# run-analysis

## 手順

1. 対象の実験フォルダを特定する。曖昧なら AskUserQuestion で確認する。
2. 実行前に確認する:
   - `Input/` にデータがあるか(なければユーザーへデータ配置を依頼。Sampleデモは自動生成されるので不要)。
   - `Params.m` の設定が依頼内容と一致しているか。パラメータ変更の依頼なら先に編集する。
3. 実行: `matlab -batch "cd('Projects/<実験フォルダ>'); Run"`
   - 特定の段だけなら `Run` の代わりに `Proc0N_*` を指定する。
   - 長時間になりそうな場合はバックグラウンド実行し、完了後にログを確認する。
4. 結果を確認する:
   - exit code と、エラー・警告の有無(ログ全文から要点を抜粋)。
   - `Cache/Proc*/` の生成有無、`Export/` の図と `manifest.json`。
5. 図を生成した場合は check-figures Skill で品質確認する。
6. 報告: 実行コマンド、結果(成功/失敗と根拠)、生成物一覧、キャッシュ利用状況(再計算された段)。

## 原則

- エラーを握りつぶして「実行しました」と報告しない。失敗はログの該当行とともに報告する。
- `Input/` のデータは読み取りのみ。変換・削除しない。
