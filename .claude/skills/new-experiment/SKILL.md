# new-experiment

## 手順

1. **必須項目を確認する(推測禁止)。** 未確定の項目があれば AskUserQuestion でまとめて1回確認する:
   - 実験名(フォルダ名は `YYYYMMDD_テーマ名`。複数人共有リポジトリなら `YYYYMMDD_名字_テーマ名`)
   - データの形式(wav/matなど)、サンプリング周波数、チャンネル対応、単位、校正値の有無
   - 何を出したいか(期待する図・数値 = 受入条件)
   - 学生が「わからない」と答えた項目は、安全側の既定値を提示して選んでもらう。
2. `Projects/<新フォルダ名>` が既存でないことを確認する。**既存フォルダは上書きしない。**
3. `Projects/_template/` の中身を `Projects/<新フォルダ名>/` へコピーする(ファイル操作で直接コピー。OS依存スクリプトは使わない)。
4. 確認した内容で穴埋めする:
   - `README.md`: 目的・測定条件・Input契約・受入条件
   - `Params.m`: expectedFs、calibrationPaPerUnit など
   - 解析内容が既に明確なら `Proc02_Analyze.m` の中身を調整する(不明ならテンプレートのまま)。
5. `matlab -batch "buildtool check"` で生成物に警告がないことを確認する。
6. `docs/roadmap/MILESTONES.md` へタスク行を追加する(書式は同ファイル冒頭の規約に従う)。追加内容をdiffで示す。
7. ユーザーへ報告: 作成場所、次にやること(データをInput/へ置く → Proc00で目視確認 → Run)。
