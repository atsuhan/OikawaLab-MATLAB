# progress-report

## 手順

1. 期間を確認する(既定: 直近1週間)。報告先(教授/ゼミSlack等)の指定があれば文体を合わせる。
2. 証拠を集める:
   - `git log --since=<期間> --oneline --stat` の要約
   - `docs/roadmap/MILESTONES.md` の状態変化(完了・進行中・追記メモ)
   - 実験フォルダの `README.md` 結果メモ、`Export/` の新しい図
3. 次の4項構成で200〜400字程度にまとめる:
   - **今週やったこと**(証拠のあるものだけ)
   - **わかったこと**(数値・図があれば1つ引用)
   - **困っていること**(ブロッカー。なければ「なし」)
   - **次にやること**(MILESTONESの次項目と対応)
4. 必要なら STATUS.md の更新(status Skill)も併せて行う。

## 原則

- 証拠のない成果を書かない。進捗率(%)は根拠がない限り書かない。
- 「できませんでした」を隠さない。困りごとこそ報告の価値。
