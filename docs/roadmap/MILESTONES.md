# MILESTONES — 作業台帳(正本)

エージェントと人間の共有タスク台帳。人間向けの現在地は `STATUS.md`(status Skillで生成)。

## 書式規約

- 1タスク1行で始める: `- [ ] **<ID>** <タイトル> ｜優先:高/中/低｜依存:<ID or なし>｜担当:<名前 or 未定>`
- IDは `E<期>-<連番>`(実験系)または `B<連番>`(基盤系)。**欠番・完了後もIDを再利用しない。**
- 直下のインデント行に詳細を書く: `目的:` `実験条件:` `受け入れ条件:` `検証:` `データ:` `メモ:`
  - 実験条件で未確定の項目は「要確認」と書く(エージェントは要確認のまま解析を進めない)。
  - 検証は実行可能なコマンドで書く。
  - メモは日付付きで追記し、過去の記録を消さない。
- 完了したら `[x]` にし、たまった項目は `archive/` へ移す(clerkの機械作業)。
